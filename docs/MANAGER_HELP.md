# Manager Help Manual

## Purpose
This manual is for manager users who own or supervise classes.

---

## 1) What a manager does
Managers typically:
- Monitor classes they manage
- Review pending enrollments
- Accept eligible students into classes
- Track attendance and absence trends
- Coordinate with teachers and admin

---

## 2) Getting started
### Use case: Login and open dashboard
1. Log in with manager account.
2. Open dashboard.
3. Confirm manager widgets and links are visible.

Expected result:
- Manager can access class and enrollment operations.

---

## 3) Manage classes
### Use case: View my classes
1. Open my classes section.
2. Open class details.
3. Confirm roster and metadata.

### Use case: Update class-level information
1. Open class edit page (if permission is granted).
2. Save updates.

Expected result:
- Class data stays accurate for enrollment and attendance.

---

## 4) Enrollment processing
### Use case: Approve student enrollment request
1. Open enrollments list.
2. Filter by your class if needed.
3. Open candidate request.
4. Accept request.

Expected result:
- Student record is created in class roster.
- Pending enrollment entry disappears.

### Use case: Bulk approve
1. Open enrollments list for selected class.
2. Use accept all when appropriate.

Expected result:
- Multiple pending requests are converted quickly.

---

## 5) Attendance and absence supervision
### Use case: Track latest absences
1. Open manager dashboard.
2. Review latest absences and class-specific trends.
3. Follow up with teachers/students where needed.

Expected result:
- Early intervention on attendance issues.

---

## 6) Collaboration workflow
### Use case: Coordinate with teacher on attendance anomalies
1. Confirm seance schedule and class assignment.
2. Review attendance entries and generated absences.
3. Ask teacher to correct attendance if needed.
4. Escalate persistent issues to admin.

Expected result:
- Fewer disputes and cleaner attendance records.

---

## 7) Common issues and fixes
- No enrollments visible:
  - Confirm you are filtering by the correct class.
  - Verify students submitted enrollment requests.
- Cannot approve request:
  - Verify role permissions (manager/admin).
  - Check if student is already in class.
- Missing class:
  - Confirm class ownership assignment.
  - Ask admin to verify class manager mapping.

---

## 8) Quick route map (for support)
- My classes: classes.manage
- Enrollments: enrollments.index, enrollments.accept, enrollments.acceptAll
- Class details: classes.show
- Dashboard: users.dashboard
